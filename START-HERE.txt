Easy Astro Studio — Reference View standalone test 0.3

This is NOT an app update or installer. It does not change Easy Astro Studio,
its projects or settings. Extract the ZIP, then open Reference-View-Test.html
in Edge or Chrome. A WebGL2-capable browser is needed for color rendering.

1. Open a local FITS stack, JPG or PNG on the left, or try the synthetic demo.
   These browser sliders test the layout, not the Windows processing algorithms.
2. Check the selected object, coordinates and field width on the right.
3. Leave DSS color — automatic mirror fallback selected, check online consent,
   and click Load online reference. The Aladin Lite 3.8.2 renderer is bundled locally; only public survey
   tiles are downloaded.
4. Automatic mode tries the SAME DSS color survey at MAST, CSIRO, China-VO,
   then ESA. Loading status names the active source. Cancel stops the local
   renderer and prevents subsequent mirror attempts. Requests already sent
   cannot be withdrawn. You can also select one mirror manually.
5. If all color attempts fail, the checked grayscale fallback option selects
   NASA SkyView explicitly; its caption identifies grayscale, not color.
6. Save downloaded color reference in this browser is enabled by default.
   Up to five downloaded color snapshots, sky coordinates, dates and credits
   are saved. Uncheck it if you do not want storage. Load saved reference
   works without online consent and without starting the renderer. Clear saved
   references removes only this small cache. File-origin storage support varies
   by browser/profile; unavailable/full storage does not prevent viewing.
7. You can always open a local reference photo. Local working/reference files
   are never uploaded and are never added to the saved-online-reference cache.

Privacy and limits
Only public sky coordinates/field width are passed to the dedicated renderer, not your
image, filename, FITS header or API keys. The bundled renderer starts only after the
online consent and Load action. Color requests go to the selected mirror(s), including ESA's CDN if redirected. If enabled, NASA is tried after
color failure. There is no background search or analytics; renderer logging is
disabled. Browser HTTP caching is separate from the five-image saved cache.

A survey is a guide to structure/framing, not predicted finished output or color
calibration. DSS plate colors, filters, depth, resolution and epoch differ from
your capture. No replacement detail is generated. No stacking/export is added.

FITS: uncompressed primary image, 2D monochrome or three-plane RGB, BITPIX
8/16/32/-32/-64 and BSCALE/BZERO. Approximate sampled asinh preview up to 1600 px,
256 MB input limit. Raw Bayer is shown as monochrome, without debayering. Use
Easy Astro Studio for accurate processing or unsupported layouts.

Online source checks found valid metadata and 512px JPEG tiles at MAST, CSIRO
and China-VO; ESA timed out then. Service availability changes. Browser checks
include no pre-consent requests, privacy, FITS/raster loading, independent
sliders, orientation, cancellation, same-survey fallback and offline cache.
The download workflow also attempts a real color render from the extracted
file-style page and verifies that the saved color result reloads offline.

See Request details for source diagnostics. Open source in browser opens a HiPS
metadata page for color mode, or the actual JPEG request for NASA mode.
Credits and renderer licensing: THIRD-PARTY-NOTICES.txt; the Aladin logo remains
on color references. No user images/private diagnostics are in the download.
