Source, privacy and reference limits
Color rendering uses Aladin Lite 3.8.2 (CDS), LGPL v3, with its logo retained. Tile data credits: Digitized Sky Survey / STScI / NASA, colored and HiPS prepared by CDS/CNRS/Unistra; mirrors credited with each image. Your working image is never passed to the renderer.
NASA SkyView / HEASARC delivers the DSS2 Red reference as a grayscale image. See SkyView for survey information. NASA mode is not a color reference. CDS service status and alternatives.
Survey: DSS2 color, STScI / photographic survey contributors; service: CDS, Strasbourg. See HiPS survey information and HiPS2FITS service for details. Survey colors, resolution, epoch and coverage differ from your capture. Check the source’s terms before redistributing imagery.
Your working image is never passed to this panel. Online access occurs only after you check consent and press Load. There are no analytics, API keys, accounts or background image searches. Local reference files stay in memory. If Save is enabled, up to five downloaded color references, coordinates and source credits are stored on this computer for offline reuse; local working/reference files are never saved by this feature. Clear saved references removes only that cache. Storage availability varies by browser. Requests may also use the normal HTTP cache. Closing this panel cancels pending requests.
